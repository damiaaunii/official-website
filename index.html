NETWORK MONITORING FOR SMEs

Know what's happening inside your network.

HOW IT WORKS

From your network
to our monitoring team.

The system continuously monitors network activity through a Mini PC deployed within the SME network. Traffic is captured, processed and analysed before monitoring information is presented to our team.

01
SME NETWORK

Network activity begins.

Employees and devices within the SME generate normal day-to-day network traffic while accessing company systems, websites and online services.

02
MINI PC

Traffic is monitored.

A compact Mini PC deployed within the company network monitors the network environment and captures traffic in real time.

03
TRAFFIC PROCESSING

Captured data is processed.

Network packet and traffic information is processed using Python so that the captured data can be prepared for further analysis.

04
BEHAVIOUR ANALYSIS

Network behaviour is analysed.

The system analyses network behaviour to help identify normal and abnormal traffic occurring within the monitored network.

05
DATA & ALERTS

Monitoring information is recorded.

Relevant monitoring information, alerts and network data are stored so that activity can be viewed and reviewed through the system.

06
ADMIN MONITORING

Our team monitors the network.

Our administrators use the web dashboard to monitor network activity and review security alerts from the SME network.
